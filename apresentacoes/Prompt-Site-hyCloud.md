# hy.cloud — Site Prompt (Conceito + Estrutura + Copy)

## O Significado de "hy" — Três Camadas

A escolha de `hy.cloud` não é estética. As duas letras carregam três significados que se encaixam no contexto BeansTech:

### 1. HY = Hunyuan (腾讯混元 — Tencent Hunyuan)

O modelo de IA frontier da Tencent chama-se **Hunyuan (混元)** — do taoísmo chinês, "a mistura primordial antes da diferenciação": o estado original do universo, antes de tudo se separar. Hunyuan é o caos primordial que contém todas as potencialidades.

**hy.cloud** = o domínio onde o Hunyuan vive. Não é um acrônimo — é as **duas primeiras letras do nome do modelo** que vai rodar nele. Assim como `glm.cloud` carrega o nome do GLM, `hy.cloud` carrega o nome do Hunyuan.

**Para a Tencent, isso é imediato:** o domínio é a cara do modelo deles. Nenhum outro domínio no mundo faz isso.

### 2. HY = High Yield (Alto Rendimento)

Em finanças e engenharia, **HY** significa *High Yield* — alto retorno sobre investimento. É o termo que fundos e engenheiros usam para descrever ativos que maximizam output por unidade de input.

**hy.cloud** = a nuvem de alto rendimento. Cada GPU-hora serve mais usuários, cada watt de energia solar processa mais tokens, cada dólar investido gera mais receita. O "yield" é o principio operacional.

**Para investidores e CFOs:** o nome comunica eficiência. Não é uma nuvem de pesquisa — é uma máquina de output.

### 3. HY = Hydro + Hybrid (Água + Híbrido)

O prefixo **hy-** aparece em *hydro* (água) e *hybrid* (híbrido) — as duas palavras que definem a infraestrutura:

- **HY-dro-Solar**: energia solar fotovoltaica + refrigeração natural costeira (Nordeste brasileiro)
- **HY-per-Secure Hybridization**: segregação lógica e física dos dados (híbrido entre nuvem soberana e enclave regulado)

**Para engenheiros de infraestrutura:** o nome carrega a arquitetura. Hydro = energia renovável. Hybrid = soberania + performance.

## A Narrativa BeansTech — Como "hy" Completa o Portfólio

A BeansTech opera três domínios de nuvem soberana, cada um com uma identidade:

| Domínio | Letra | Modelo | Significado | Função |
|---|---|---|---|---|
| **z.cloud** | Z (7ª letra) | GLM (Z.ai) | A consoante da perfeição — "a que completa" | A nuvem-mãe: the AI cloud that proves what it answers |
| **glm.cloud** | GLM | GLM-5.3 | O nome do modelo | O produto: API do GLM em território brasileiro |
| **hy.cloud** | hy | Hunyuan (Tencent) | O nome do modelo + High Yield + Hydro | O motor: compute Hunyuan para LATAM regulado |

Juntas, as três formam o **portfólio de nuvens soberanas** da BeansTech:
- `z.cloud` é a marca guarda-chuva
- `glm.cloud` serve o ecossistema Z.ai
- `hy.cloud` serve o ecossistema Tencent

**A fórmula:**
```
z.cloud = z.ai     → GLM-5.3     → inteligência clínica/jurídica (profundidade)
hy.cloud = Tencent → Hunyuan/Hy4 → compute de alto rendimento (volume)
glm.cloud = GLM    → GLM API     → tokens soberanos (transacional)
```

Cada nuvem tem seu motor, seu domínio, e seu público. Todas compartilham a mesma infra: data centers PB/CE, identidade BeansTech ID, compliance LGPD/CFM/BACEN.
